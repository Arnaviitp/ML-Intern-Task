## 💡 Prompt Formulas

### Basic Formula
```
[Subject] + [Style] + [Quality] + [Lighting] + [Composition]
```

Example:
```
Majestic eagle, wildlife photography, highly detailed, 
golden hour lighting, close-up portrait
```

### Advanced Formula
```
[Subject] + [Action/Pose] + [Environment] + [Style] + 
[Lighting] + [Camera/Composition] + [Quality] + [Mood]
```

Example:
```
Ancient wizard casting spell, mystical forest clearing, 
fantasy art style, magical glowing lighting, wide angle dramatic view, 
highly detailed 8k, epic mysterious atmosphere
```

## ⚡ Quick Tips

### Making Prompts More Specific
❌ Weak: "A cat"
✅ Better: "Orange tabby cat sitting on windowsill, soft natural lighting, 
professional pet photography, highly detailed"

### Adding Atmosphere
❌ Basic: "Mountain landscape"
✅ Enhanced: "Majestic mountain landscape at golden hour, dramatic clouds, 
misty valleys, epic scale, professional photography, highly detailed"

### Style Consistency
Use consistent style keywords throughout your prompt:
- For photorealism: "professional photography", "DSLR", "8k", "photorealistic"
- For art: "digital art", "oil painting", "watercolor", "artistic"
- For fantasy: "fantasy art", "magical", "ethereal", "epic"

## 🎯 Negative Prompt Examples

### General Quality Improvement
```
blurry, low quality, low resolution, distorted, deformed, 
ugly, bad anatomy, bad proportions, watermark, signature, text
```

### For Photorealistic Images
```
blurry, low quality, cartoon, anime, painting, drawing, 
unrealistic, fake, bad lighting, overexposed, underexposed
```

### For Portraits
```
blurry, low quality, bad anatomy, deformed face, disfigured, 
bad proportions, extra limbs, missing limbs, ugly, distorted features
```

### For Landscapes
```
blurry, low quality, oversaturated, unrealistic colors, 
bad composition, cluttered, messy, distorted
```

## 📝 Practice Exercises

1. Start with a simple prompt and gradually add details
2. Try the same subject in different art styles
3. Experiment with lighting variations
4. Combine multiple techniques
5. Use negative prompts to refine results

---

**Remember**: The best prompts are specific, descriptive, and include quality enhancers!
